# Images

This folder stores:
- annotated intersection photographs,
- precedent images,
- diagrams,
- geometry sketches,
- GIS screenshots,
- thermal maps,
- and conceptual illustrations.

Potential future categories:
- `/intersections/`
- `/precedents/`
- `/gis/`
- `/diagrams/`

## Example Annotation Methodology
Images to gather:

- intersections with long wait times,
- high sun exposure,
- large curb radii,
- transit adjacency,
- missing shade.

For each image:

rename clearly:
e.g.: `burnet-koenig-northwest-corner-01.jpg`

And:

- add a small markdown note below each image later, explaining:
  - why the site matters,
  - observed constraints,
  - possible conflicts.
